Setup Guide

From download to your first game in a few minutes.

Requirements

Windows PC

  • Windows 11
  • NVIDIA GPU (NVENC is used for encoding)
  • Latest NVIDIA drivers
  • Wired ethernet to your router
  • SteamVR installed if you play SteamVR games

Apple Vision Pro

  • KRVR from the App Store
  • Same local network as your PC
  • 5 GHz Wi-Fi, Wi-Fi 6 recommended
Streaming quality is decided by your network. A wired PC and a 5 GHz access point in the same room as the headset make the biggest difference of anything on this page.

Upgrading from KRVR 1.x

KRVR 2.0 uses a new Windows server. Run the new installer over your existing install; it replaces the old server and there is nothing to uninstall first. Close SteamVR and any VR game before you run it, because Windows will not let the installer replace files they are holding.

Step 1 — Install the server on your PC

  1. Close SteamVR and any VR game
  2. Download KRVR-Setup-v2.0.0.exe from the Download for PC button
  3. Run it. The installer registers the KRVR OpenXR runtime, the SteamVR driver and the firewall rules for you
  4. KRVR appears on your desktop and in the Start menu
The installer is signed by KRXR LTD. If the installer reports that files are still the old version, something was holding them open: close SteamVR and any game and run it again.

Step 2 — Install the Vision Pro app

  1. Open the App Store on your Vision Pro and search for KRVR
  2. Tap Get
  3. KRVR appears on your home view

Step 3 — Connect

  1. Open KRVR on your PC
  2. If your PC has more than one network adapter, pick the one on the same network as your Vision Pro from the IP list
  3. Press Start
  4. Open KRVR on your Vision Pro. It looks for your PC on the local network and shows it when found
  5. Tap Connect
No pairing codes, no QR. If the headset cannot see the PC, type the address shown in the PC app into the headset instead.

Step 4 — Launch a game

  1. Connect first, then launch the game on the PC from Steam, its own launcher or the desktop
  2. The game appears in your headset

OpenXR games

These run through KRVR's own OpenXR runtime, with no SteamVR in the chain. If the game has a display or VR mode setting, set it to OpenXR.

SteamVR games

These launch as normal. SteamVR starts with the KRVR driver and shows KRVR as the headset. No extra software, no compatibility layers.

Tuning the picture

In the headset, while you play

Open the pill and go to Quality. Everything here applies live.

  • Bitrate — how much video the network carries. Higher is sharper if your Wi-Fi keeps up
  • Fovea size — how big the full-detail region around your gaze is. The stream size it produces is shown under the slider
  • Periphery compress — how much the edges outside the fovea are reduced
  • Sharpen — post-sharpening on the decoded picture

On the PC, before you connect

  • Resolution — the render size the game is asked for
  • Fovea density — pixel density in the fovea relative to the periphery
  • FoV scale — trims the rendered field of view to save GPU time
  • Stream rate — the target frame rate
  • IPD — your eye separation in millimetres
  • Encoder preset and 10-bit encode — quality versus encoder speed
Start with the defaults. Raise Bitrate first, then Fovea size. If the picture stutters, your network is the limit, not the sliders.

Motion Smoothing

Found under Performance in the pill.

  • On locks a game that cannot keep up with the display to the steady rate it can hold, so every frame lands on an even step. The stable choice for demanding games
  • Off lets the game run free: every frame it makes ships at once, for the lowest latency, but frame timing is uneven when the game falls behind

A game that keeps up is untouched either way. The switch applies live, mid-game.

Mixed reality windows

See your wheel, rig, keyboard or controllers through the game. Open Masks in the pill and follow the wizard: it places a passthrough window where you point, and the window stays anchored in the room between sessions. Use Immersion in the pill to fade the whole game towards passthrough instead, and FOV Crop to trim the edges of the picture.

Audio and microphone

  • Audio output in the PC app chooses where game sound goes: Headset or Desktop. One or the other, never both
  • Game audio picks the Windows playback device KRVR captures from. Leave it on your default device unless you know why

Microphone, one-time setup

Sound to the headset needs nothing extra. Your voice going the other way does, because Windows only lets games read from a microphone device, and KRVR needs one to write into. VB-Cable provides it.

  1. Download VB-Cable (free), run its installer as administrator, reboot if it asks. The KRVR app on the PC offers this link itself the first time it finds no cable
  2. Leave Headset mic in the KRVR app on Auto; it picks up the cable by itself. You can also choose CABLE Input there explicitly
  3. In your game, Discord or team radio, choose CABLE Output as the microphone
If CABLE Input is not in the list after installing, Windows left the device disabled: open Sound settings, Recording devices, right-click CABLE Input and choose Enable. Mute any time from the pill with the Microphone toggle.

Troubleshooting

Headset cannot find the PC

  • Both devices must be on the same network. Guest networks and some mesh systems isolate clients
  • Check the PC app is Started and the right adapter is chosen in its IP list
  • Allow KRVR through Windows Firewall on both Private and Public networks
  • Disconnect any VPN on the PC
  • Type the address shown in the PC app into the headset

Game opens on the monitor instead of the headset

  • Connect before launching the game
  • OpenXR games: set the game's display mode to OpenXR
  • SteamVR games: SteamVR should list KRVR as the headset. If it shows another headset, restart SteamVR after KRVR is connected

Installer says files are still the old version

  • SteamVR or a game was holding the files. Close them and run the installer again
  • If it persists, restart the PC and run the installer before opening anything else

Picture is soft or stutters

  • Raise Bitrate in Quality, then Fovea size
  • Make sure the headset is on 5 GHz, not 2.4 GHz, and the PC is on ethernet
  • Turn Motion Smoothing on for a game that cannot keep up

No sound in the headset

  • Set Audio output to Headset in the PC app
  • Check Game audio points at the device the game plays through

Headset sleep ends the session

  • visionOS drops the network when the headset sleeps. Reconnect after you put it back on
